- **调研方式**：公开网络渠道搜集（企业官网、品牌官方商城、电商政企采购渠道、公开新闻稿/财报资料），未使用任何非公开渠道

## 本项目栏目定位（调研对标基准）

新蓝恒成官网「产品与服务」栏目 = 华为政企 ICT 产品销售与解决方案（企业网络设备、服务器及 AI 算力、商用电脑）＋ 海康威视智能安防 ＋ 科大讯飞 AI ＋ 希沃智慧教育，另有鸿蒙智行专区（整车销售）。据此，本报告分两层调研同类竞品：

| 层级 | 调研对象 | 对应本报告章节 | 回答的问题 |
|---|---|---|---|
| 企业层 | 同类华为生态经销商 / ICT 集成服务商（神州数码、软通动力、中软国际、佳都科技） | 第一部分 | 同类企业如何组织「产品与服务」栏目、卖什么、服务模式与客群定位 |
| 产品线层 | 本项目六大产品线各自的对标品牌 | 第二、三部分 | 各产品线的竞品格局、当前公开价格体系（档位/计费周期/权益差异）、目标客群 |

## 核心发现摘要

1. **企业层范式**：四家同类企业的「产品与服务」栏目均采用「产品线 + 行业方案」双层结构，华为生态伙伴身份均显性独立呈现；B 端业务全部为项目制/集采/分销报价，官网无公开价格——公开标价只在硬件电商渠道与软件订阅制产品上存在。
2. **网络设备价格带**：24 口千兆接入交换机华为/H3C 电商挂牌约 ¥1,500–3,400，锐捷同档偏高（¥4,500–6,650）；Wi-Fi 7 AP 三家均无公开价（需询价）。
3. **算力/服务器价格带**：通用 2U 服务器约 ¥3–7 万，8 卡推理整机约 ¥12 万，8 卡训练服务器 ¥163–266 万；华为昇腾训练整机仅项目制报价。
4. **政企电脑**：华为擎云是唯一官方商城全程挂牌的品牌（笔记本 ¥5,199–12,999、信创台机含屏 ¥4,599–8,599），批采价可低至 ¥4,850。
5. **安防硬件价格梯度**：同类摄像机「电商挂牌 → 批发 → 政采」价差约 2.5–4 倍；海康 400 万半球电商 ¥422–571、8 路 NVR ¥607–984、门禁 ¥1,399–4,999。
6. **教育/会议平板**：希沃 75 英寸 ¥1.05–2 万、86 英寸 ¥1.2–1.66 万；MAXHUB ¥6,299–4.1 万跨度最大；三家配套软件订阅均无公开标价。
7. **AI 平台计费（最完整的价格体系样本）**：讯飞按次数套餐 ¥1,300–30 万/年 + 大模型 tokens 计费；百度千帆按 tokens + 订阅双轨（如 ERNIE 4.5 输入 ¥0.004/千 tokens）；腾讯云「免费月额度 → 资源包 → 后付费」三层机制——**三档定价 + 免费额度 + 企业权益差异**是「价格体系方案」栏目的最佳参考模板。
8. **整车对标**：尊界 S800（72.8 万起）所处行政旗舰价位带竞品为蔚来 ET9（76.8 万起）、极氪 009 光辉（78.9 万）等；尚界 H5（15.98 万起）所处中型 SUV 价位带竞品为 Model Y（26.35 万起）、宋 PLUS EV（14.98 万起）等。

## 对栏目规划的参考建议（基于数据归纳）

- 栏目结构可参照「产品线 + 行业方案」双层范式，并像四家竞品一样把**华为生态伙伴身份独立显性呈现**。
- 硬件类目可参考电商挂牌价设定「起价展示 + 询价」模式；软件/平台类目可参考 AI 平台的「免费额度 → 套餐档位 → 企业定制」三档结构设计价格展示。
- 各产品线页面的目标客群表述可对齐竞品官网的行业关键词（政府/金融/教育/医疗/制造/运营商等）。

## 五、调研备注与缺口

1. **大华 NVR 零售挂牌价**：京东旗舰店有售但抓取页面未返回价格，标注「未查到公开价」；工程侧多为项目报价。
2. **希沃/鸿合/MAXHUB 软件订阅**：三家官网均无公开软件订阅标价，教学/会议软件随硬件打包赠送为主，政采渠道按项目打包——官网内容规划建议以「随机附赠+可选服务包」话术呈现，勿引用具体订阅价。
3. **宇视消费级价格**：宇视主攻工程渠道，公开零售价多见于政采合同与经销批发（半球 500–610元/台政采口径）。
4. **安防硬件成交价规律**：同型号海康半球，官方/电商挂牌 422–571元，批发渠道 160–236元（大华更低），政采合同 500–610元——「挂牌→批发→政采」三层价差约 2.5–4 倍，官网展示建议采用电商挂牌价口径。
5. **AI 平台价格时效性**：千帆价格文档镜像（apifox）部分为 2023–2024 老口径（如 ERNIE-Bot 4.0 0.12元/千tokens），新模型（ERNIE 4.5、DeepSeek 托管）单价已大幅下探至 0.004元/千tokens 量级；引用时注意标注模型代际。
6. **汽车价格**：均为官方指导价（建议零售价），奔驰E级终端有约8万以上优惠、尊界S800上市期有权益包，实际成交以门店为准。
